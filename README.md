# Biblia Latinoamericana — app para el celular

App web instalable (funciona sin internet) con el texto de la Biblia Latinoamericana,
buscador de citas (también habladas), referencias marginales, historial con notas y modo oscuro.

- **`biblia-app/`** — la app que se publica (Cloudflare, GitHub Pages o Netlify).
- **`GUIA-PUBLICAR.md`** — cómo publicarla y compartirla.
- **`Instructivo-App-Biblia.pdf`** — cómo convertirla en aplicación de Android y iPhone.
- **`herramientas/REVISION.md`** — revisión del texto: lo que se corrigió y lo que falta en el PDF.
- **`herramientas/`** — convertidor del PDF, pruebas de integridad y generador del diseño.

Cada cambio en la rama `main` se puede publicar automáticamente (ver `GUIA-PUBLICAR.md`).
